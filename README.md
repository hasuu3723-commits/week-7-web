
# SpendWise – Smart Money Management

## Project Description

SpendWise is an interactive budgeting web application designed to help users manage their monthly budgets, track expenses, calculate remaining balances, and monitor their spending habits.

The application allows users to enter their monthly budget and expenses and receive instant financial feedback.

## Technologies Used

- HTML5 – Website structure
- CSS3 – Website styling and responsive design
- JavaScript – Calculations and interactive functionality
- GitHub – Source code hosting and version control
- Netlify – Website hosting and deployment

## Deployment Process Summary

1. Organized the project files into one folder.
2. Created a public GitHub repository.
3. Uploaded index.html, style.css, script.js, and README.md.
4. Created a Netlify account using GitHub.
5. Connected the SpendWise GitHub repository to Netlify.
6. Configured the publish directory to the project root.
7. Deployed the website.
8. Changed the default Netlify site name to a meaningful project name.
9. Tested the live website.
10. Updated the project on GitHub and verified automatic deployment.

## Challenges Encountered During Deployment

**Challenge 1: Connecting GitHub to Netlify**

Solution: Signed in to Netlify using GitHub and authorized repository access.

**Challenge 2: Configuring deployment settings**

Solution: Selected the project root directory as the publish directory because SpendWise is a simple HTML, CSS, and JavaScript application.

**Challenge 3: Testing the live website**

Solution: Checked that the HTML, CSS, and JavaScript files loaded correctly and that the budgeting features worked.

**Challenge 4: Automatic deployment**

Solution: Made a visible change to the project, pushed it to GitHub, and checked that Netlify deployed the latest version.
